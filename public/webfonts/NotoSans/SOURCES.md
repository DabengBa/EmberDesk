# Noto webfont sources

The bundled Noto Sans, Noto Sans Devanagari, and Noto Sans Mono came from
[Google Fonts at commit `cc5661d43cd4f9aad5567033a8e15ca28dc35c86`](https://github.com/google/fonts/tree/cc5661d43cd4f9aad5567033a8e15ca28dc35c86/ofl)
under `notosans`, `notosansdevanagari`, and `notosansmono`. Each family is
distributed with its upstream SIL Open Font License.

The WOFF2 files retain the variable weight axis from 100 to 900. Width is
fixed at the normal setting (100) where the source offers a width axis. The
character sets follow the previous bundled fonts. The Devanagari face retains
the script blocks and shaping data formerly bundled in the upright Sans face.
