# Derived Processing Notes

This directory holds reproducible sandbox proofs and derived implementation narratives, not durable documentation owners.

Current implementation facts are recoverable from source, types and tests; use `rg`, LSP and the focused test suite. Non-inferable trade-offs, invariants and external quirks belong to `.docs/adr/` and `.docs/tech/`. Derived notes generated from those flows go stale silently and MUST NOT be used as authority. New process notes MUST be kept in untracked `.tmp/`.
